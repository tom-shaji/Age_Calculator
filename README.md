# Age Calculator

A simple, command-line Python application that calculates a person's age and provides details about their next birthday.

## Features
- Calculates current age in years.
- Calculates total age in months and days.
- Displays the date of the user's next birthday.
- Shows how many days are remaining until the next birthday.
- Includes input validation to handle incorrect date formats or future dates.
- Allows calculating multiple ages without restarting the program.
- Automatically accounts for leap years.

## Prerequisites
- Python 3.x installed on your system.

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the project directory.
3. Run the following command:

```bash
python main.py
```
